ℹ️ YL Toolkit 소개

운영 목적

YL Toolkit은 실제 제품 구매와 DIY 준비 과정에서 RP 조합, 포인트 효율, 희석량과 원가를 반복 계산해야 하는 불편을 줄이기 위해 만든 개인 제작 무료 도구입니다. 프로그래밍 지식이 없어도 휴대전화에서 쉽게 사용할 수 있도록 모바일 중심으로 제작합니다.

계산 결과는 참고용입니다. 실제 주문, 판매 또는 제작 전에는 공식 정보와 사용 조건을 사용자가 최종 확인해야 합니다.

현재 제공 기능

RP 최적 구매 계산기

보유한 리워드 포인트에 맞는 제품 조합을 찾고 포함·제외 제품과 수량을 설정할 수 있습니다. 실제 주문 전 공식 주문 화면의 RP, 가격과 재고를 확인해주세요.

화장품·DIY 제품 원가 계산기

구매 용량과 실제 사용량을 기준으로 재료 원가와 개당 원가를 계산하고, 입력한 마진율에 따른 권장 판매가를 확인할 수 있습니다.

에센셜오일 희석 계산기

총 용량과 희석 농도, 1ml당 방울 수를 기준으로 예상 방울 수와 에센셜오일·베이스오일 용량을 계산합니다.

포인트 구매 효율 비교기

회원가와 PV로 1PV당 제품가치를 계산해 제품 사이의 금액 대응 차이를 비교합니다.

제품 정보센터

등록된 8개 에센셜오일의 공식 사실정보와 YL Toolkit 편집 설명, 가격·RP를 구분해 제공합니다.

데이터 분석 콘텐츠

99개 제품의 실제 데이터와 계산기 공식을 바탕으로 분포, RP 조합과 원가 사례를 분석합니다.

데이터 관리 원칙

제품명, 회원가격과 RP는 운영자가 확인한 자료를 기준으로 관리합니다. 공식 주문 화면과 차이가 있으면 공식 주문 화면을 우선해주세요.

제품 가격, RP, 판매 여부와 재고는 변경될 수 있습니다. 데이터 오류는 문의 페이지에서 제보할 수 있으며 가격·RP는 실시간 공식 DB가 아닌 수동 관리 데이터입니다. 제품 페이지는 공식 사실정보와 YL Toolkit 향 가이드를 구분하며, 공식 주문 화면과 라벨을 최종 기준으로 합니다.

계산 정확도 관리 원칙

화면의 계산 기준은 실제 코드의 계산식과 동일하게 적용합니다. 변경 시 기존 기능의 결과를 다시 비교하고 브라우저와 모바일 화면에서 실제 동작을 확인합니다.

계산 결과는 절대적인 보증이나 의료·법률·세무 등 전문 자문이 아닙니다.

운영 및 업데이트 원칙

  • 기능 추가와 오류 수정은 버전별 업데이트 내역에 기록합니다.
  • 기존 기능을 깨뜨리지 않는 최소 수정 원칙을 따릅니다.
  • 모바일 사용성을 우선해 화면을 점검합니다.
  • 사용자 제보를 확인해 데이터와 기능을 개선합니다.

비공식 관계 고지

YL Toolkit은 Young Living 공식 사이트나 공식 주문 시스템이 아닙니다. Young Living 및 관련 상표는 해당 권리자에게 있으며, 이 사이트는 개인이 제작·관리하는 계산 도구입니다.

향후 개발 방향

제품 데이터베이스 고도화, 판매가 계산 기능 개선, 디퓨저·레시피 계산기와 관리자 기능 등을 개발 목표로 검토하고 있습니다. 이는 확정된 출시 일정이나 제공 약속이 아닙니다.
