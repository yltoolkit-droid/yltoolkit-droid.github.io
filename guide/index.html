가이드와 계산기를 함께 사용하는 방법

  1. 처음 사용하는 계산기의 가이드를 먼저 읽습니다.
  2. 입력값과 단위를 확인한 뒤 계산기로 이동합니다.
  3. 결과 항목을 가이드의 해석 방법과 비교합니다.
  4. 공식 주문 화면이나 실제 제작 조건을 최종 확인합니다.

계산 결과가 예상과 다를 때

입력 단위, 선택 조건, 데이터 기준일과 브라우저 버전을 확인해주세요. 문제가 계속되면 입력값과 표시 결과를 정리해 문의 페이지로 알려주세요.
