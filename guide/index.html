처음 사용하는 방법

  1. 필요한 계산기를 선택합니다.
  2. 입력값과 단위를 확인합니다.
  3. 계산 버튼을 눌러 결과를 만듭니다.
  4. 결과 항목과 계산 기준을 읽습니다.
  5. 공식 주문 화면 또는 실제 제작 조건과 비교합니다.
  6. 오류가 있다면 입력값과 표시 결과를 정리해 문의합니다.

계산기별 빠른 안내

RP 계산기

보유 RP에 맞는 제품 조합을 찾을 때 사용합니다. 보유 RP, 포함·제외 제품, 포함 수량, 중복 허용과 최대 수량이 주요 입력값입니다. 결과에서는 사용 RP, 남는 RP, 제품 수량과 총 금액을 확인하고 공식 주문 화면과 비교해주세요. RP 계산기 열기

원가 계산기

화장품·DIY 제품의 실제 사용 원가와 권장 판매가를 검토할 때 사용합니다. 구매 용량, 구매 금액, 사용량, 기타 비용, 완성 수량과 마진율을 입력합니다. 재료 원가, 총 원가, 개당 원가와 권장 판매가를 확인하고 누락한 수수료나 세금이 없는지 검토해주세요. 원가 계산기 열기

희석 계산기

총 용량과 목표 희석 농도에 필요한 예상 방울 수를 계산할 때 사용합니다. 총 용량, 희석률, 1ml당 방울 수와 방울 처리 방식이 주요 입력값입니다. 오일 ml, 방울 수, 베이스 ml와 실제 계산 희석률을 확인하고 제품별 안전정보를 별도로 확인해주세요. 희석 계산기 열기

자주 발생하는 입력 오류

  • 숫자 입력란에 문자를 입력하거나 값을 비워둔 경우
  • 0 또는 음수를 입력한 경우
  • 원가 계산기에서 구매 용량과 사용량의 단위를 다르게 입력한 경우
  • 밀도가 다른 원료의 g과 ml를 같은 값으로 혼용한 경우
  • 희석 계산기에서 1ml당 방울 수를 실제 드로퍼와 관계없이 고정값으로 생각한 경우
  • RP 계산기에서 같은 제품을 포함·제외하려 하거나 필요한 선택을 빠뜨린 경우
  • 제품별 최대 수량과 같은 제품 여러 개 허용 설정을 혼동한 경우

결과가 예상과 다를 때

  1. 입력값, 단위와 선택 설정을 다시 확인합니다.
  2. 제품 데이터 기준일과 페이지 설명을 확인합니다.
  3. 브라우저를 새로고침하고 다시 계산합니다.
  4. 푸터의 최신 버전 표시와 업데이트 내역을 확인합니다.
  5. RP·가격은 공식 주문 화면과 비교합니다.
  6. 계속 다르면 문의 페이지에 재현 정보를 보냅니다.

문의할 때 함께 보내면 좋은 정보

  • 사용한 계산기
  • 입력한 값과 선택 설정
  • 예상한 결과와 실제 표시된 결과
  • 사용한 기기와 브라우저
  • 가능한 경우 민감정보가 없는 오류 화면 캡처

주민등록번호, 계좌번호, 비밀번호, 건강정보 등 민감한 개인정보는 보내지 마세요.
