🧮 PV 계산기 가이드

보유 PV를 남김없이 활용하고 필요한 제품을 우선 반영하려면 단순 합산보다 조건을 함께 비교해야 합니다. 이 가이드는 PV 계산기가 필요한 이유와 결과를 읽는 방법을 설명합니다.

왜 PV 계산기가 필요한가요?

제품마다 회원가격과 PV가 서로 다르고, 필요한 제품의 수량까지 고려하면 머릿속 계산만으로는 남는 PV를 최소화하기 어렵습니다. 특히 꼭 포함할 제품과 제외할 제품이 있을 때는 조합 수가 빠르게 늘어납니다.

PV 계산기는 보유 PV, 포함·제외 제품, 수량과 우선 기준을 한 번에 반영해 주문 전에 비교할 수 있도록 돕습니다. 계산 결과는 주문 결정을 대신하는 것이 아니라 공식 주문 화면에서 최종 확인하기 위한 참고 자료입니다.

사용 방법

  1. 보유 PV를 입력합니다.
  2. 같은 제품 여러 개 허용 여부를 선택합니다.
  3. 추천 후보에 적용할 제품별 최대 수량을 선택합니다.
  4. 제품 개수 최소, 결제금액 낮은 순, 고가 제품 우선 중 우선 기준을 선택합니다.
  5. 꼭 필요한 제품은 제품 목록에서 포함을 선택합니다.
  6. 원하지 않는 제품은 제외를 선택합니다.
  7. 포함 제품이 여러 개 필요하면 나타나는 수량 입력란에 개수를 입력합니다.
  8. 계산하기 버튼을 선택합니다.
  9. 추천 결과의 사용 PV와 남는 PV를 확인합니다.
  10. 실제 주문 화면에서 제품 정보와 주문 가능 여부를 최종 확인합니다.

계산 기준

  • 포함 제품은 제품 PV × 수량을 보유 PV에서 먼저 차감하고, 회원가격 × 수량도 총 금액에 먼저 합산합니다.
  • 제외 제품과 이미 포함한 제품은 남은 PV의 추천 후보에서 제거합니다.
  • 포함 제품을 반영하고 남은 PV에 대해 추천 조합을 계산합니다.
  • 남는 PV가 적은 조합을 먼저 비교하고, 같은 조건에서는 선택한 우선 기준에 따라 제품 수 또는 금액을 비교합니다.
  • 같은 제품 여러 개 허용을 끄면 추천 후보별 수량은 1개로 제한됩니다. 켜면 선택한 제품별 최대 수량까지 후보에 반영됩니다.
  • PV는 코드에서 소수 둘째 자리까지 비교할 수 있도록 100을 곱한 정수로 반올림해 계산합니다.

이 계산은 현재 등록 데이터와 설정에 따른 추천이며 절대적인 최저가나 유일한 최적 조합을 보장하지 않습니다.

실제 사용 예시

파촐리 2개를 포함하는 경우

보유 PV를 100 PV로 입력하고 파촐리 에센셜 오일 15ml를 포함한 뒤 수량을 2개로 지정합니다. 파촐리 1개의 PV는 34.75이므로 34.75 × 2 = 69.50 PV가 먼저 차감되고, 회원가격도 49,400원 × 2 = 98,800원이 먼저 합산됩니다. 계산기는 남은 30.50 PV 안에서 다른 제품 조합을 찾으며 결과에는 파촐리 에센셜 오일 15ml × 2로 표시됩니다.

제품을 제외하는 경우

페퍼민트 에센셜 오일 15ml를 제외로 선택하면 해당 제품은 추천 후보에서 빠지고, 나머지 등록 제품으로 조합을 계산합니다.

결과 해석 방법

  • 사용 PV: 추천 조합에 포함된 모든 제품의 PV 합계입니다.
  • 남는 PV: 입력한 보유 PV에서 사용 PV를 뺀 값입니다.
  • 제품 수: 같은 제품의 수량을 포함한 전체 제품 개수입니다.
  • 제품별 PV: 해당 제품의 PV × 수량으로 계산한 합계입니다.
  • 제품별 금액: 해당 제품의 회원가격 × 수량으로 계산한 합계입니다.
  • 결과 복사: 첫 번째 추천 조합의 보유 PV, 사용 PV, 남는 PV, 총 금액과 제품 목록을 복사합니다.

제품 데이터 기준과 갱신 정책

현재 등록 제품은 총 100개이며 데이터 확인 기준일은 2026-08-04입니다. 제품명, 회원가격과 PV는 사이트 운영자가 확인한 자료를 기준으로 관리합니다.

가격, PV, 판매 여부와 재고는 변경될 수 있습니다. 사이트 정보와 공식 주문 화면이 다르면 공식 주문 화면을 우선해주세요. 오류를 발견했다면 문의 페이지에서 알려주세요.

자주 묻는 질문

계산 결과와 실제 주문 금액이 다른 이유는 무엇인가요?

가격, PV, 판매 여부나 재고가 변경되었거나 사이트 데이터 반영 시점이 다를 수 있습니다. 실제 주문 화면의 정보를 우선해주세요.

포함 제품은 어떻게 계산되나요?

선택한 제품의 PV와 회원가격에 포함 수량을 곱해 먼저 반영한 뒤, 남은 PV로 다른 제품을 추천합니다.

포함 제품 수량을 2개 이상 지정할 수 있나요?

네. 포함을 선택하면 나타나는 수량 입력란에서 2개 이상을 지정할 수 있습니다. 포함 제품의 수량은 제품별 최대 수량 설정과 별도로 먼저 반영됩니다.

제외 제품은 결과에서 완전히 빠지나요?

네. 제외로 선택한 제품은 추천 후보에서 제거됩니다. 같은 제품을 포함으로 바꾸면 제외 선택은 해제됩니다.

남는 PV가 생기는 이유는 무엇인가요?

등록 제품의 PV 조합만 사용하므로 입력한 PV와 정확히 일치하는 조합이 없을 수 있습니다. 이 경우 계산 가능한 조합 중 남는 PV가 적은 결과를 먼저 보여줍니다.

같은 제품 여러 개 허용과 제품별 최대 수량은 무엇인가요?

중복 허용을 켜면 추천 후보의 각 제품을 선택한 최대 수량까지 사용할 수 있고, 끄면 후보별 1개만 사용합니다.

제품 정보 오류는 어디에 알려야 하나요?

문의 페이지를 통해 제품명, 표시된 가격 또는 PV와 확인한 내용을 알려주세요.
